Under the Banker's Algorithm for deadlock avoidance in an asynchronous multi-threaded kernel, assume the system state currently satisfies the safety criterion. If thread T₃ requests allocation of resource vector R_k, which invariant mathematically proves that granting R_k maintains a safe state?

Assessment Options & Distractor Ledger
A

The requested allocation vector satisfies R_k ≤ Available, and the remaining system available vector satisfies Available - R_k ≥ 0.

Distractor
Distractor Rationale: Tests superficial availability check. Confuses immediate resource availability with long-term safety sequence existence.
B

There exists at least one permutation sequence of all currently active threads ⟨T₁, T₂, ..., Tₙ⟩ such that for every thread Tᵢ, its maximum remaining need Need[i] ≤ Available + ∑ Allocation[j] for all predecessors j < i.

CORRECT ANSWER
Pedagogical Anchor: Verifies formal definition of a safe sequence. Students must deduce that temporary state transition is speculative until a valid termination topological sort is confirmed.
C

The Resource Allocation Graph (RAG) contains no immediate directed cycles involving node T₃ after hypothetical assignment edge insertion.

Distractor
Distractor Rationale: Cycle-freedom in RAG is only sufficient when all resource types have exactly 1 instance, failing for multi-instance systems.
D

Thread T₃ releases at least one held lock instance before requesting additional units in vector R_k.

Distractor
Distractor Rationale: Confuses dynamic avoidance (Banker's) with static prevention (hold-and-wait elimination protocol).
