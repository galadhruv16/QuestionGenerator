In an asynchronous distributed kernel implementing Dijkstra's Banker's Algorithm for deadlock avoidance, assume a cluster state with 5 concurrent worker threads and 3 non-shareable resource types R1, R2, R3. Under what mathematical precondition will the allocation vector grant guarantee that the state transition preserves global safety?
